# Tastify Arabian Mandi & Restaurant — Multi-page website

## Open locally
1. Extract this folder.
2. Open it in VS Code.
3. Run `index.html` with Live Server, or open the file directly in a browser.
4. Keep the `assets` folder alongside the HTML files.

## Pages
- `index.html` — home
- `story.html` — restaurant story
- `menu.html` — photographed menu reference (view only; no ordering)
- `gallery.html` — restaurant image gallery with lightbox
- `visit.html` — address, click-to-call, WhatsApp and Google Maps directions
- `privacy-policy.html` — privacy notice template
- `terms-and-conditions.html` — terms template
- `cookie-policy.html` — cookie notice
- `accessibility.html` — accessibility statement
- `404.html` — not-found page
