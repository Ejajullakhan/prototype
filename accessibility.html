Accessibility Statement

Accessibility information for the Tastify restaurant showcase website.

Ongoing improvementsNeed help?

Last updated: 6 October 2026

We want the Tastify website to be usable by as many visitors as possible. The site is built with semantic HTML, keyboard-accessible navigation, visible focus behavior, descriptive image text, responsive layouts, and reduced-motion preferences where supported.

Ongoing improvements

Accessibility is an ongoing effort. Third-party imagery, embedded resources, browser differences, or content changes may affect accessibility. This statement is not a claim of full compliance with any particular standard.

Need help?

If you have trouble accessing information on this website, please contact Tastify by phone at +91 99668 88060. If the issue concerns the website itself, the site owner should add a dedicated support contact when one is available.
